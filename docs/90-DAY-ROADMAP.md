# 90-Day Roadmap

Planning sequence only; dates begin after Founder-approved project kickoff. Durations depend on account access, API review and existing infrastructure.

## Days 1-15 — Audit and foundation
- Inventory existing QUAMIX products, website/CMS, brand assets, social accounts, CRM, analytics and repositories.
- Create approved fact register with live/planned/retired status and source owners.
- Finalize voice, audience, claims policy and content pillars.
- Implement data model, campaign/content schemas and deterministic approval package.
- Deliver: audited integration register, brand knowledge base v1, offline tests and threat model.

## Days 16-30 — Strategy and text MVP
- Implement strategist, editorial planner and content director workflows.
- Create campaign brief, content calendar and six-channel text variants.
- Add content versioning, source provenance and review checklist.
- Deliver: one QUAMIX pilot campaign as drafts, no public posting.

## Days 31-45 — Creative production and approval UX
- Add image/carousel/audio/video asset workflows.
- Build approval dashboard with package preview, revision and audit history.
- Test approval invalidation when text, media, channel, account or schedule changes.
- Deliver: complete multimedia approval package in staging.

## Days 46-60 — Controlled social integrations
- Verify API eligibility and obtain per-channel authorization.
- Implement draft-only adapters and provider validation.
- Test rate limits, token revocation, retry/idempotency and provider receipts.
- Deliver: channel adapter acceptance reports; publishing remains disabled until release gate.

## Days 61-75 — Community and inbound CRM
- Connect authorized inbound forms/messages and existing CRM after audit.
- Implement consent records, lead pipeline, explainable qualification and escalation.
- Keep replies and outbound follow-ups as drafts.
- Deliver: inbound lead workflow with privacy and opt-out tests.

## Days 76-90 — Analytics and operational readiness
- Connect validated web/social/CRM metrics.
- Build campaign and funnel dashboards with data freshness and attribution caveats.
- Add monitoring, backup/restore, incident runbook and kill switch.
- Complete staging security review and end-to-end tests.
- Deliver: operational readiness report and separate Founder decision on production activation.

## Release gates
No paid spend, production deployment, live publishing, bulk messaging or protected commercial/financial claims are included automatically in this roadmap.
